# ABTalks AI Interview Agent - Prompts

Below are the major prompts used to design, architect, and generate the code for this production-ready enterprise AI system.

## 1. Initial Architecture & Setup Prompt
> "I need to build an enterprise-level AI Interview System named 'ABTalks AI Interview Agent'. Set up the foundational architecture for a production-ready web application. Create a modern, responsive layout that includes sections for system architecture, capabilities, live playground, and feedback. Ensure it has a dark mode aesthetic with glassmorphism effects, dynamic animations, and a highly modular component structure. It needs to look like a premium, state-of-the-art AI product."

## 2. UI/UX Refinement & "Vibes" Prompt
> "Let's refine the UI to make it feel extremely premium and 'wow' the user at first glance. Apply a vibrant, futuristic color palette—focusing on deep blacks, subtle glowing accents, and smooth gradients. The interface should feel alive. Incorporate micro-animations, hover effects on cards, and smooth scrolling. The hero section needs to be striking, featuring a 3D avatar and a dynamic grid overlay."

## 3. Capabilities & Features Prompt
> "Build the 'Capabilities' and 'Architecture' sections. Integrate the mock data for candidates and the curriculum. The UI should display various AI evaluation metrics, interview analysis features, and use interactive cards to showcase how the AI handles technical assessments, behavioral questions, and real-time feedback. Please use clean, reusable React components."

## 4. Documentation & Drawer Integration Prompt
> "Implement a 'Documentation Drawer' that slides in seamlessly from the side to display technical specifications, memory, and architecture details. It should use modern transitions and not disrupt the user's workflow. Ensure the codebase strictly follows best practices for maintainability."
